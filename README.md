# Сервис для хранения данных о пользователях

Проект реализует сервис для хранения и управления информацией о пользователях 
с возможностью аутентификации, разграничением прав доступа и системой ограничений 
для обычных пользователей. 
Система обеспечивает безопасный доступ к ресурсам посредством передачи cookies.



## Основные возможности сервиса:

- Аутентификация: Все запросы к API защищены средствами cookie-аутентификации.
- Доступ для администраторов: Полный доступ к просмотру и изменению любых данных пользователей.
- Права обычных пользователей: Ограниченный доступ к информации других пользователей и право на изменение части собственных данных.
- Автоматизированная документация: Интеграция Swagger для автоматического формирования документаций API.
- Контейнеризация: Вся система работает в Docker-контейнерах, что облегчает развертывание.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/V-nika-viktorovna/storage_user_data.git
   ```
2. Создайте и активируйте виртуальное окружение:

    ```bash
    python -m venv venv
    ```
3. Установите зависимости:
   
   ```bash
    pip install -r requirements.txt
    ```

4. Настройте переменные окружения:
    ```bash
    .env.example
    ```
5. Локальный запуск проекта:

   ```bash
    uvicorn main:app --reload

    ```

6. Сборка образов Docker и запуск сервисов:

   ```bash
    docker compose build
   
    docker compose up   
   
   ```
7. Проверка работоспособности

   ```bash
   Проверьте работоспособность приложения по адресу http://localhost:8000/docs 
   или воспользуйтесь инструментами вроде Postman для отправки запросов 
   непосредственно к API.
   Ознакомьтесь с документацией по адресу http://localhost:8000/docs
   
   ```
8. Для создания первого администратора используйте команду в терминале PyCharm:

   ```bash
   python csu.py
   ```
   Или запустите модуль csu.py любым удобным для вас способом.

```
│   └── admin.py      # обработчики административных запросов

├── models.py         # модели данных (ORM-модели)
├── pyproject.toml    # проектные метаданные aerich
├── README.md         # руководство по проекту
├── requirements.txt  # зависимости Python
└── schemas.py        # схемы Pydantic для проверки входящих и исходящих данных

```
